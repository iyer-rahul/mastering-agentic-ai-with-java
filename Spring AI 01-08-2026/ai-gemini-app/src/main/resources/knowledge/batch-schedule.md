Java Fundamentals (java-101) and Python for Absolute Beginners (py-101) are

## Attendance

Live sessions are recorded and uploaded within 12 hours, so missing a class is not
fatal. However, to be eligible for the certificate you need 70% live attendance or
you must clear the end-of-course assessment with 60% or above.

## Doubt sessions

Every Sunday, 5:00 PM to 6:00 PM IST, open to all live-batch learners across all
courses. No registration needed, the link is pinned in the Discord server.

## Batch size

Live batches are capped at 60 learners so that mentors can actually answer questions.
Once seats run out the course shows as full and the next batch opens roughly 5 weeks
later.

## Recording access

Live batch recordings stay available for 18 months from the batch start date.
Self-paced course access is lifetime.
